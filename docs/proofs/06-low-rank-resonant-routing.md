# 证明 06 · 低秩共振路由调制（LRRM）的四项定理

对应设计：`docs/design/11-low-rank-resonant-routing.md`
对应实现：**尚未落地**（本文是设计期的证明义务，实现落地时必须逐条复测，见 §6 的验收判据）。
依赖的已证结论：`docs/proofs/03`（值中性直通门的路径梯度）、`docs/proofs/04`（投影符号的
arcsine 保序律 `τ(k,d)` 与 `k = ⌈d·sin²(πτ/2)⌉` 反解）、`docs/proofs/00` Theorem 5（块场调制的
有界性 `κ = α(γ_max + c)`）。

---

## 0. 记号与前提

主干隐维 `d`，专家数 `E`，寻址迹宽 `k ≤ d`。

- `W ∈ R^{k×d}`：SBF 寻址用的查询投影（`block_field` 的地址器），**已存在于前向中**；
- `z = Wh ∈ R^k`：一次前向为知识块寻址已经算出的查询向量；
- `P_e ∈ R^k, e=1..E`：专家原型（LRRM 新增的唯一大块）；
- `A_e ∈ R^{d×r}, r` 为残差秩，`R_e = A_eᵀ` 给出残差分数 `⟨R_e h, 1⟩` 的简记；
- `p_e`：由 `{s_e}` softmax 得到的软选择概率；`n`：硬选择出的下标。

**显式假设**（去掉任何一条，下面相应定理不成立）：

(A1) `W` 的行向量非退化（`rank(W) = min(k,d) = k`），且其行范数的 RMS 与均值同阶（经验上由
高斯初始化保证；`_trace_scale` 就是用 RMS 归一的）。
(A2) 专家代表方向 `u_e ∈ R^d` 非零且已知（由该专家负责子空间的质心给出，初始化期可得）。
(A3) LM 损失对每个被选中的 token 非退化：`∂L/∂h'_t ≠ 0`。
(A4) 所有原型共享**同一个**缩放因子，不做逐专家归一化（`docs/proofs/04` 实测：逐块归一化把
τ 从 1.000 打到 0.865，逐专家归一化同理）。

## 定理 1（成本上界；对应 F1 的 6× 每步退化）

**陈述**：现有 HiCL 打分头的每 token 乘法代价为
`C_hicl = c₁·(d·ed + ed·ed) + ed·E`，其中 `e = expansion_factor`（现取 4）、`ed = e·d`；
LRRM 的代价为 `C_lrrm = d·k + k·E + 2rd`。当 `k ≤ d`、`r ≤ d/4` 时
`C_lrrm ≤ (1 + 2r/d)·d² + kE`，而 `C_hicl ≥ 4d² + 16d² = 20d²`，故

```
C_hicl / C_lrrm  ≥  20d² / (d² + 2rd + kE)  ≥  20 / (1 + 2r/d + E·k/d²)
```

代入本仓实测几何：`d = 256, k = 168（τ=0.60 反解）, E = 8, r = 8`
⇒ 比值 `≥ 20 / (1 + 0.0625 + 0.0205) ≈ 18.4`。

**依据**：矩阵向量乘的代价是维数乘积之和（定义）；`z = Wh` 之所以**不计入** `C_lrrm` 的增量，
是因为它在同一次前向中为知识块寻址已经计算过——**共享**是本定理的全部杠杆，也是它与
"再建一个小 MLP"的区别。

**经验对应**：F1 实测头激活使主机档每步从 ~10 s 涨到 ~65 s（6×）。定理 1 的预测与之一致：
DG 编码器的 `4d·4d = 16d²` 项是主成本，被 LRRM 消掉后不应再出现同量级退化。
**该 6× 必须复测为 LRRM 落地后的验收项，不允许拿上式代替测量。**

## 定理 2（保序性；有效性）

**陈述**：在 (A1)(A2)(A4) 下，取 RPI 同构的原型初始化

```
P_e = (ρ/rms(W))·(W Wᵀ)⁺ W u_e ,
```

则对任意 `h`，`s_e(h) = ⟨Wh, P_e⟩ = (ρ/rms(W))·⟨h, Π u_e⟩`，其中 `Π = Wᵀ(W Wᵀ)⁺W` 是
到 `row(W)` 的正交投影。于是 **step-0 的专家排序 = 内容在 `row(W)` 上的投影像的排序**。
进一步，若 `u_e` 之间两两夹角服从各向同性分布，则由 `docs/proofs/04` 定理（arcsine 律），
LRRM 排序与真实内容排序的 Kendall τ 满足

```
τ = (2/π)·arcsin(√(k/d)) + O(d^{-1/2}) .
```

**推论（必须说出口的代价）**：`k/d` 越小，路由越只看得见内容的 `k` 维投影。本仓实测
`d=4096, τ=0.60 ⇒ k=2681`，即 7B 档的原型常驻约 `E·k·4B`（`E=8` 时约 86 KB），可忽略；
但若某档把 `k` 设成常数（旧实现 `block_trace_dim=256` 的毛病），`τ≈0.16`，**共振初始化几乎不起作用**。
故 LRRM 的可行性与 A68 的结论绑定：`k` 必须由 `block_alignment_target` 随 `d` 反解。

## 定理 3（梯度覆盖；必要性）

**陈述**：令 `Δ_e = ∂h'/∂s_e` 为调制对隐态的雅可比。
(i) **硬 top-k 且分数不进权重**时，`∂L/∂P_e ≡ 0`（对未被选中的 `e` 几乎必然），
因为 `s_e` 只进入一个分段常值映射。这解释了 F2：`w_got`、`got_cluster_proj.weight`
在 0.01B 档连续三次前向梯度均为 `None`——不是 bug，是**该构造的必然**。
(ii) 用 `docs/proofs/03` 的值中性直通门 `g_e = 1 + (p_e − stopgrad(p_e))` 时

```
∂L/∂P_e = Σ_t ⟨∂L/∂h'_t, Δ_e⟩ · p_e(1[n_t = e] − p_e) ,
```

由 (A3) 右端在 `0 < p_e < 1` 时非零，故 `P_e` 与产生 `s_e` 的 `W` 支路都进入梯度。

**必要性论证（为什么不能用别的办法）**：软选择（对全部 `E` 求和并回传）虽也有梯度，但一旦把
`E` 换成 628 个知识块这类大规模候选集，代价按 `E·d` 线性膨胀——`docs/proofs/03` 已算过
628 块 ≈ `6.9e11 FLOPs/token`，比主干贵约 500×。直通门在**保持值精确等于 1**（前向逐位不变）
的前提下拿到软选择的路径梯度，是同时满足"有梯度"与"不改变推理"的唯一已知构造。

## 定理 4（与被替代机制的对比；不弱于性的**有限**陈述）

诚实结论：**LRRM 不是 HiCL 的严格超集**。HiCL 分数是
`s_e^{hicl} = ⟨MLP(h), prot_e⟩`，`MLP: R^d → R^{4d}`；LRRM 分数是
`s_e^{lrrm} = ⟨h, Π u_e⟩·ρ/rms + ⟨R_e, h⟩`，即"低秩投影 + 秩 r 残差"。二者关系为：

- **被包含的方向**：若 `MLP` 的像空间落在 `row(W)` 张成的空间内，则两者等价（取 `P = W⁻ᵀ prot`），
  此时 LRRM 以 `~1/18` 的代价表达同一族分数（定理 1 + 本条）。
- **被丢掉的表达**：`MLP` 的非线性（GELU）带来的**非单调**打分不能被线性 `⟨Wh, P_e⟩` 复刻；
  秩 `r` 残差只能补回线性部分。**这是真实的取舍**，所以 LRRM 的合法性论证只能建立在
  定理 2 的保序性（排序质量）与定理 3 的梯度覆盖（可训练性）上，**不得声称"表达力必然更强"**。
- 若日后需要非线性，正解是把 `s_e` 交给一个共享的低秩 MLP（`d→r→E`），代价 `2rd`，
  而不是回到 `4d` 维私有编码器。

## 5. 数值与稳定性说明（近似位置）

- `(WWᵀ)⁺` 用 `lstsq`/伪逆实现，条件数依赖 `W`；`docs/design/10` 已规定 `ρ/rms(W)` 的**全局**
  缩放（禁止逐专家归一化，(A4)）。
- 直通门分母 `sigmoid(g).detach()` 需下界保护，沿用 `docs/proofs/03` 的 `safe_clamp`。
- 有界性继承 `docs/proofs/00` Theorem 5：`κ = α(γ_max + c)`，故加入 `s_e` 项不会使调制幅度失控。

## 6. 实现落地时的验收判据（未测即不算达标）

1. **成本**：同一档同一序列长，`头关闭 / HiCL / LRRM` 三态的秒/步对比；LRRM 必须显著低于 HiCL
   （定理 1 的预测比值需实测核对，写出实际倍数）。
2. **梯度覆盖**：`d=64` 与 `d=256` **两档**都测 `lrrm_traces.grad` 与 `sparse_gate_*.grad`
   非 `None`（直接针对 F2 的失败）。
3. **保序性**：路由排序与内容投影排序的 Kendall τ 实测值 vs `(2/π)arcsin√(k/d)` 预测值。
4. **训练覆盖**：`verify_checkpoint` 的 `parameters_unchanged`（A93 后的诚实口径）必须**不升**，
   并给出前后数值。
5. **不破坏既有性质**：`tools/test/test_moe_routing_contract.py`、`test_block_sparse_attn_contract`、
   `test_sparsity_objective_contract` 全绿；留出集 CE 曲线不断。
