## 1. 要解决的问题（都是量出来的，不是想象出来的）

| 编号 | 实测事实 | 出处 |
|---|---|---|
| F1 | 辅助路由头（HiCL / GOT / SoftMoE）激活后，主机档**每步耗时约 6×**（seq256 从 ~10 s/步 涨到 ~65 s/步） | §82 ⑤ |
| F2 | 在 0.01B 几何上，三个头**全部不进计算图**：`w_hicl.grad`、`w_got.grad`、`got_cluster_proj.weight.grad` 连续三次前向均为 `None`，而两档 MoE 声明字段同构（只差 `hidden_size`） | §84/§86 |
| F3 | 头一族曾长期"声明存在但永不训练"（步数门用模块私有计数器 + `==` 门闩），修复后才进入优化器 | §79/§80 |
| F4 | HiCL 的结构是 `hicl_dg_dim = hidden_size * 4` 的 DG 编码器 + `E × 4d` 原型；GOT 另建 token 图 + `d × E` 投影 | `model/moe/gate.py:211-224` |

F1 与 F2 是**同一枚硬币的两面**：每个头都自带一套独立的隐藏维度投影（F4），所以它**既贵**（独立大矩阵）
**又脆弱**（任何一档的几何/阶段判定一不对，整族就从图上消失，且消失是静默的）。
继续接线只能让某一档通起来，**换不来"任意档必然进图"这个性质**。性质要由构造给出 —— 这就是 LRRM。

## 2. 机制定义

记主干隐维 `d`，专家数 `E`。SBF 的寻址侧已经有（本设计**不新建**）：

- 查询投影 `W ∈ R^{k×d}`（`k = block_trace_dim`，由 `block_alignment_target` 反解 arcsine 律，`docs/proofs/04`）；
- 知识块 trace `T_i ∈ R^{k}`，以及 RPI 配对初始化 `T_i = (ρ/rms)·(WWᵀ)⁺W u_i`；
- 值中性直通选择 `g = 1 + (p_c − stopgrad(p_c))`（`docs/proofs/03`）。

**LRRM 的定义**：专家路由得分不再由新造的隐藏维度产生，而是在**同一个寻址度量**下，
给每个专家一个 trace 型原型 `P_e ∈ R^{k}`：

```
s_e(h)  =  ρ_r · < W h , P_e > / sqrt(k)          # 共振项：与知识块寻址同度量、同 W
r_e(h)  =  < A_e , h >  ,  A_e ∈ R^{d×r}, r = rank_residual   # 残差项：找回被低秩丢掉的那部分
logits  =  logits_standard  +  Σ_e g_e · ( s_e(h) + r_e(h) )
```

三条构造性约束（**这是创新所在，不是调参**）：

1. **共享度量**：`W` 就是寻址的 `W`。路由与查算分离**不是两套相似度**，而是一个度量的两个读出面。
   边际算力只有 `k·E`（`Wh` 在同一次前向里已经为了寻址算过）。
2. **配对初始化**：`P_e` 用与 RPI 完全相同的最小二乘构造，取自该专家负责子空间的代表方向
   `u_e`：`P_e = (ρ_r/rms(W))·(WWᵀ)⁺W u_e`。于是 **step-0 的路由排序 = 内容排序在 `row(W)` 上的投影像**，
   排序保真度由 arcsine 律 `τ = (2/π)·arcsin√(k/d)` **给定**，而不是指望训练自己学出来。
3. **梯度必然存在**：`g_e` 取 A21 的值中性直通形式。由 `docs/proofs/03` 的路径梯度
   `∂L/∂P_e = Σ_t ⟨∂L/∂h_t, Δ_e⟩ · p_e(1[n_t=e] − p_e)`，只要 LM 损失非退化，`P_e` 就拿到梯度 ——
   **与档位几何、与 warmup 阶段判定无关**。F2 那类"整族静默消失"在构造上不可能发生。

**与现有头的关系（不并存，避免冗余）**：HiCL 的 DG 编码器与原型被 `(共享 W + P_e)` 取代；
GOT 的 token 图不再参与路由打分，其簇统计降为**观测量**（不再是可微分支）；
SoftMoE 的 `gate_k/gate_v` 与预算项保留（它是均衡机制不是打分头，与 LRRM 正交）。
